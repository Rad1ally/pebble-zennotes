# ZenNotes for Pebble

ZenNotes(サーバー版)に保存しているノートを、Pebble Time 2(emery)で一覧・閲覧する読み取り専用アプリ。

- 時計側 `src/c/main.c`: フォルダ単位の一覧(フォルダはアイコン付き、ノートは新しい順)、「最近」(全ノートの新しい順)、「タグ」(frontmatter のタグ別の一覧)、音声入力でのタイトル検索。画面下に Vim 風のステータスバー(モード・ボタンの案内・位置・読み込みの進捗)を表示する。Pebble Time 2 ではタッチ操作(一覧のスワイプ・タップ、本文のスクロール、右スワイプで戻る)にも対応。選択中の長いタイトルは横スクロールで全文を表示する。ノート本文は Markdown を見出し・箇条書き・チェックボックス・引用・callout・表(はみ出す表は横スクロール)付きで表示する。コードブロックは先頭3行と言語名を表示し、タップかSELECTで行番号・シンタックスハイライト付きのコード画面を開く。日本語はシステムフォントの言語パックで表示する。
- スマホ側 `src/pkjs/index.js`: ZenNotes API(`GET /api/notes`、`GET /api/notes/read?path=`)を Bearer トークンで呼ぶ。ノート一覧はキャッシュし、フォルダ移動・最近・検索はキャッシュから返す。本文は表示用のブロック形式に変換して 2000 バイトずつ時計に送る。
- 設定(サーバーURL・トークン・表示するフォルダ・テーマ(ダーク/ライト)・文字サイズ(大/標準)・ステータスバー・スクロール位置の目盛り・言語(日本語/English))は Pebble アプリの設定画面から入れる。
- 一覧で SELECT を長押しすると、ノート一覧をサーバーから取り直す。
- 32KB を超える長いノートはページに分け、末尾の「続きを読む」で次のページを開く。
- ノート画面で SELECT を長押しすると見出しとリンクの一覧(TOC)を開く。見出しを選ぶとそこへ移動し、リンクを選ぶとそのノートを開く。
- 画像(`![[画像.png]]`、`![説明](URL)`、ノートからの相対パス)は帯で示し、タップか SELECT で画像の画面を開く。スマホ側で画像を読み込み(PNG・JPEG・WebP・SVG など)、画面に収まるよう縮めて64色に減色(誤差拡散)してから送る。vault 内の画像は ZenNotes の `/api/assets/raw` から取得する。
- wikilink(`[[ノート名]]`、`[[ノート名|表示名]]`)は 🔗 と色で示し、タップでリンク先のノートを開く(1行に複数あれば TOC のリンク欄を開く)。行き先は Obsidian と同じく、パス、同じフォルダの同名ノート、パスがいちばん短い同名ノートの順で探す。リンク先から BACK で元のノートに戻る。
- 開いたノートとノート一覧はスマホに保存し、サーバーにつながらないときはその内容を表示する(最大30件)。
- ノートごとのスクロール位置と、最後に開いていたフォルダを覚えておき、次に開いたときに戻る。
- サーバーURLとトークンは初期値なし。インストール後に設定画面で入れる。
- Android(CoreApp)前提。

ビルドと導入の手順は [Pebble-SDK-Setup.md](Pebble-SDK-Setup.md) を参照。

```bash
pebble build
```
